# IT Asset Inventory API

A REST API for managing IT assets, built with Python, FastAPI,
SQLite and Docker.

## Project Goals

The goal of this project is to build and containerize a simple
IT asset management application while gaining practical
experience with REST APIs, Docker and Linux administration.

## Planned Features

- Create IT asset records
- List and retrieve assets
- Update existing asset information
- Delete asset records
- Store data in an SQLite database
- Run the application in Docker
- Manage the application using Docker Compose
- Persist database data between container restarts

## Technology Stack

- Python
- FastAPI
- SQLite
- Docker
- Docker Compose
- Git and GitHub

## Project Status

In progress.

## Learning Objectives

- Build and test a REST API
- Understand Docker images and containers
- Write and use a Dockerfile
- Configure applications with Docker Compose
- Manage persistent data
- Document and version-control a technical project
